# stronger-site

The landing page for [Stronger](https://github.com/hassanaziz0012/stronger), a workout tracker for Android. Live at <https://stronger.hassandev.me>.

Plain HTML, CSS and JavaScript with no build step. Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

Screenshots and the clip in `assets/img` are the app running on a Pixel 9. The fonts in `assets/fonts` are Google Sans Flex (OFL), the same instances the app ships.
